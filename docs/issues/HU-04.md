# HU-04. Generación masiva y descarga de certificados por grupo/curso

## Descripción

Como docente o administrador, quiero generar automáticamente los certificados para los estudiantes aprobados de un curso o grupo específico, para descargar todos los documentos listos en un archivo comprimido sin tener que hacerlos uno por uno.

**Rol:** Administrador (ADMIN) o docente (DOCENTE) del grupo

### Alcance

- Selección del curso y el grupo de origen, con vinculación automática de la plantilla correspondiente.
- Validación de aprobación contra las notas registradas y el máximo de faltas del curso.
- Generación automática de los certificados en segundo plano.
- Descarga de un archivo .zip con los PDF individuales de alta calidad.

## Criterios de aceptación

- [ ] Dado un curso y un grupo seleccionados, cuando el sistema busca la plantilla, entonces usa la plantilla específica del grupo si existe; si no existe, usa la plantilla general del curso e informa cuál se está usando.
- [ ] Dado un curso y un grupo sin ninguna plantilla asociada, cuando el sistema busca la plantilla, entonces informa que no hay plantilla disponible y ofrece crear una.
- [ ] Dado un grupo con estudiantes inscritos, cuando el usuario pide la vista previa, entonces el sistema muestra cuántos estudiantes hay en total y cuántos cumplen la condición de aprobación.
- [ ] Dado un grupo cuyo curso tiene rúbrica y notas registradas, cuando el sistema filtra a los aprobados, entonces incluye únicamente a quienes alcanzan la nota mínima del curso y no superan el máximo de faltas.
- [ ] Dado un grupo sin rúbrica o sin jornadas de asistencia registradas, cuando el sistema intenta determinar la condición de cada estudiante, entonces los clasifica como pendientes y explica que falta información para decidir.
- [ ] Dado un grupo donde ningún estudiante cumple la condición, cuando el usuario intenta generar, entonces el sistema no inicia la generación y explica por qué no hay certificados que emitir.
- [ ] Dado al menos un estudiante aprobado, cuando el usuario pulsa «Generar Certificados», entonces el sistema inicia el proceso en segundo plano y muestra el progreso sin bloquear la interfaz.
- [ ] Dado un proceso en curso, cuando el usuario observa la pantalla, entonces ve cuántos certificados se han generado sobre el total previsto.
- [ ] Dado un proceso finalizado con éxito, cuando el usuario pulsa «Descargar», entonces recibe un archivo .zip que contiene un PDF por estudiante aprobado.
- [ ] Dado un PDF generado, cuando se abre, entonces muestra la imagen base de la plantilla a una página de tamaño carta horizontal, con los textos y las firmas en las posiciones guardadas.
- [ ] Dado un PDF generado, cuando se revisan sus datos, entonces el nombre del estudiante, el nombre del curso, el grupo, la nota final y la fecha de emisión aparecen con los valores de ese estudiante en particular, nunca con los de otro.
- [ ] Dado un archivo dentro del .zip, cuando se observa su nombre, entonces sigue el patrón Certificado_<apellidos y nombres>_<curso>.pdf.
- [ ] Dado un proceso finalizado, cuando el usuario reintenta la descarga, entonces puede volver a descargar el mismo archivo.
- [ ] Dado un docente autenticado, cuando intenta generar para un grupo que no es suyo, entonces el sistema se lo impide aunque conozca la dirección de la página.

## Criterios no funcionales

- La generación no bloquea la interfaz: el proceso se realiza en segundo plano y el usuario puede seguir usando el sistema.
- Los certificados se emiten en PDF con texto vectorial, sin pérdida de nitidez al imprimir en tamaño real.
- Un certificado nunca se emite para un estudiante que el reporte de notas clasifique como pendiente, sin certificado o solo por asistencia: ambas funciones comparten la misma regla de aprobación.

## Fuera de alcance

- El envío de los certificados por correo o mensajería.
- La firma digital criptográfica que garantice la autenticidad del documento.
