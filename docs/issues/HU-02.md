# HU-02. Creación y personalización de plantillas de certificados (diagramador)

## Descripción

Como docente o administrador, quiero subir una imagen base de fondo y utilizar un diagramador visual para colocar textos dinámicos y firmas, para generar una plantilla de certificado reutilizable con variables automáticas.

**Rol:** Administrador (ADMIN) o docente (DOCENTE)

### Alcance

- Subida de la imagen base con validación de resolución y formato.
- Diagramador visual con clic para añadir bloques de texto y arrastre para posicionarlos.
- Inserción de variables dinámicas predefinidas en el contenido del texto.
- Incorporación de firmas desde el repositorio de firmas del sistema.
- Guardado de la configuración en coordenadas porcentuales.

## Criterios de aceptación

- [ ] Dado el formulario de creación de plantilla, cuando el usuario selecciona un archivo que no es PNG ni JPG, entonces el sistema rechaza el archivo indicando el formato aceptado.
- [ ] Dado un archivo menor a 1200 × 800 px, cuando el usuario intenta subirlo como imagen base, entonces el sistema lo rechaza indicando la resolución mínima y la actual.
- [ ] Dado un archivo mayor a 2500 × 1750 px, cuando el usuario intenta subirlo como imagen base, entonces el sistema lo rechaza indicando la resolución máxima y la actual.
- [ ] Dado un archivo que cumple las condiciones, cuando el usuario confirma la subida, entonces el sistema la guarda y la muestra como fondo del lienzo del diagramador.
- [ ] Dado un fondo cargado en el lienzo, cuando el usuario hace clic sobre la previsualización, entonces el sistema añade un bloque de texto centrado exactamente en el punto del clic.
- [ ] Dado un bloque de texto centrado, cuando se muestra en el lienzo, entonces crece hacia ambos lados a partir del punto de inserción, de modo que el texto largo no se salga del lienzo.
- [ ] Dado un bloque de texto o una firma sobre el lienzo, cuando el usuario lo arrastra a otra posición, entonces el bloque se mueve en tiempo real y queda alineado con la posición final.
- [ ] Dado un bloque de texto seleccionado, cuando el usuario elige una variable del panel de variables, entonces la variable se inserta en el texto en la posición del cursor.
- [ ] Dado un bloque de texto, cuando el usuario ajusta alineación, tamaño de fuente o color, entonces los cambios se reflejan de inmediato en la previsualización.
- [ ] Dado el repositorio de firmas del sistema, cuando el usuario arrastra una firma al lienzo, entonces la firma se incorpora como elemento y puede moverse igual que un bloque de texto.
- [ ] Dado una plantilla con elementos posicionados, cuando el usuario la guarda y vuelve a abrirla, entonces el fondo y todos los elementos reaparecen en las mismas posiciones, con el mismo tamaño, alineación y contenido.
- [ ] Dado una plantilla sin nombre, cuando el usuario pulsa «Guardar Plantilla», entonces el sistema no guarda y señala el campo nombre como obligatorio.
- [ ] Dado una plantilla asociada a un curso, cuando el usuario guarda, entonces el sistema la registra con ese curso y, si eligió un grupo, con ese grupo.

## Criterios no funcionales

- Las posiciones se guardan en porcentajes, de modo que el mismo diseño funcione aunque la imagen se muestre a distinto tamaño en pantalla.
- La validación de resolución se realiza en el navegador para dar respuesta inmediata y de nuevo en el servidor, que es el que decide.
- La previsualización muestra un texto de ejemplo por cada variable para que el usuario ubique el bloque sin necesidad de generar un certificado.

## Fuera de alcance

- La administración de las firmas como tales: corresponde a HU-03.
- La impresión o descarga de los certificados: corresponde a HU-04.
