# HU-01. Visualización y gestión del administrador de plantillas de certificados

## Descripción

Como administrador o docente del sistema, quiero acceder a una vista principal que liste las plantillas de certificados creadas y filtrarlas por curso o grupo, para poder administrar, reutilizar o crear nuevos diseños de certificados de manera organizada.

**Rol:** Administrador (ADMIN) o docente (DOCENTE)

### Alcance

- Vista principal en la ruta /certificados, alcanzable desde el ítem «Certificados» del menú lateral.
- Filtro jerárquico: selector de Cursos que habilita el selector de Grupos.
- Tabla con nombre de la plantilla, curso y grupo asociados, fecha de creación, cantidad de elementos y acciones.
- Acciones por plantilla: Editar, Duplicar y Eliminar.
- Acceso directo a la creación de plantillas y a la generación masiva.

## Criterios de aceptación

- [ ] Dado un usuario con sesión iniciada en el sistema, cuando hace clic en «Certificados» del menú lateral, entonces el sistema lo dirige a la vista del administrador de certificados en /certificados.
- [ ] Dado un usuario autenticado, cuando abre la vista de certificados, entonces ve un selector de Cursos que lista los cursos del periodo actual.
- [ ] Dado que no se ha elegido ningún curso, cuando el usuario observa el selector de Grupos, entonces este aparece deshabilitado y vacío.
- [ ] Dado un curso seleccionado, cuando el usuario elige un grupo en el segundo selector, entonces el listado muestra únicamente las plantillas asociadas a ese curso y ese grupo.
- [ ] Dado un curso seleccionado sin grupo, cuando el usuario deja el segundo selector vacío, entonces el listado muestra las plantillas generales del curso junto con las de sus grupos.
- [ ] Dado un grupo sin plantilla propia, cuando el usuario filtra por ese grupo, entonces el sistema informa que ese grupo usará la plantilla general del curso.
- [ ] Dado que existen plantillas creadas, cuando se las muestra el listado, entonces cada fila indica el nombre de la plantilla, el curso, el grupo asociado o la etiqueta «General del curso», la cantidad de elementos sobre la imagen base y la fecha de creación.
- [ ] Dado un listado con plantillas, cuando el usuario pulsa «Editar» en una fila, entonces el sistema abre el diagramador en modo de edición con el fondo y los elementos ya cargados.
- [ ] Dado un listado con plantillas, cuando el usuario pulsa «Duplicar», entonces el sistema crea una copia de la plantilla con todos sus elementos, suggested nombre «<nombre> (copia)» y la misma asociación de curso y grupo.
- [ ] Dado un listado con plantillas, cuando el usuario pulsa «Eliminar», entonces el sistema pide confirmación y solo borra la plantilla tras la confirmación.
- [ ] Dado que existen plantillas registradas y la generación está en proceso, cuando el usuario regresa a la vista, entonces el sistema muestra el estado del proceso sin perder los filtros aplicados.
- [ ] Dado que el listado está vacío para los filtros actuales, cuando se muestra la vista, entonces el sistema ofrece crear una plantilla en lugar de mostrar una tabla vacía sin salida.
- [ ] Dado un docente autenticado, cuando intenta abrir la plantilla perteneciente a un grupo de otro docente, entonces el sistema se lo impide aunque conozca la dirección de la página.

## Criterios no funcionales

- El listado se muestra en menos de 2 segundos con el volumen actual de plantillas.
- Los mensajes de error y de estado vacío se presentan en español, en términos del dominio (curso, grupo, plantilla).

## Fuera de alcance

- El diseño del contenido de la plantilla: eso corresponde al diagramador (HU-02).
- La carga de la imagen base y de las firmas: HU-02 y HU-03.
