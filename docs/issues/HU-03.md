# HU-03. Gestión y subida de firmas digitalizadas

## Descripción

Como administrador, quiero subir y gestionar las imágenes de las firmas de autoridades o docentes, para poder seleccionarlas y arrastrarlas fácilmente dentro del diagramador de certificados.

**Rol:** Administrador (ADMIN)

### Alcance

- Apartado dedicado a la gestión de firmas dentro de la configuración de certificados.
- Subida de firmas en PNG o JPG, idealmente con fondo transparente.
- Conversión automática a WebP en el servidor para optimizar el almacenamiento.
- Repositorio visual con las firmas disponibles, permitiendo eliminar firmas y actualizar el nombre de su propietario.

## Criterios de aceptación

- [ ] Dado un administrador en el módulo de firmas, cuando abre la vista, entonces ve el listado en galería de las firmas disponibles con su nombre de propietario.
- [ ] Dado un administrador, cuando selecciona un archivo que no es PNG ni JPG, entonces el sistema rechaza el archivo indicando el formato aceptado.
- [ ] Dado un archivo de firma en PNG o JPG, cuando el usuario confirma la subida, entonces el servidor lo convierte a WebP y lo guarda, y la galería muestra la firma ya convertida.
- [ ] Dado una firma con fondo transparente, cuando se convierte a WebP, entonces la transparencia se conserva.
- [ ] Dado una firma guardada, cuando el usuario edita el nombre de su propietario y confirma, entonces el sistema guarda el nuevo nombre y la galería lo muestra actualizado.
- [ ] Dado una firma que no es usada por ninguna plantilla, cuando el usuario solicita eliminarla y confirma, entonces el sistema la borra del listado y del almacenamiento.
- [ ] Dado una firma utilizada por al menos una plantilla, cuando el usuario intenta eliminarla, entonces el sistema no la borra e informa cuántas plantillas la utilizan y cuáles son.
- [ ] Dado que el repositorio no tiene firmas, cuando se muestra la vista, entonces el sistema indica que aún no hay firmas cargadas y ofrece la opción de subir la primera.
- [ ] Dado un nombre de propietario vacío, cuando el usuario intenta guardar, entonces el sistema lo rechaza e indica que el nombre es obligatorio.

## Criterios no funcionales

- La conversión a WebP reduce el peso almacenado sin pérdida visible de calidad en la firma impresa.
- El tamaño máximo de archivo admitido se informa en la propia vista antes de la carga.

## Fuera de alcance

- La validación de identidad de quien firma: el sistema no verifica la autenticidad de la firma, solo la gestiona como imagen.
